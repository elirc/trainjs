# JavaScript Job-Readiness Course

This repository is a docs-first JavaScript training course for a learner who already understands basic programming ideas but needs stronger JavaScript skills to become competitive for a junior software engineering role.

The course is designed as a 12-16 week path. It starts with core language fluency, moves into browser and server work, layers in testing and TypeScript, and finishes with a portfolio-quality capstone.

After the junior track, the repository also includes an advanced continuation section for mid-level and senior-oriented growth in system design and architecture.

## Who This Is For

- You can read code and write simple logic in at least one language.
- You understand variables, loops, and functions at a basic level.
- You do not yet feel confident building real JavaScript applications.
- You want a path that explains both the "how" and the "why".

## What You Will Be Able To Do

By the end of this course, you should be able to:

- read and write idiomatic JavaScript in both browser and Node.js environments
- understand scope, closures, objects, prototypes, classes, modules, and async code
- build interactive browser features with the DOM and browser APIs
- create and consume JSON APIs
- build a simple backend with Node.js and Express-style routing
- test small units of code and debug common issues
- add TypeScript to a JavaScript project without panic
- explain your decisions clearly in a junior-level interview

## Suggested Pace

- `Weeks 1-2`: Lessons 1-2
- `Weeks 3-4`: Lessons 3-4
- `Weeks 5-6`: Lessons 5-6
- `Weeks 7-8`: Lessons 7-8
- `Weeks 9-10`: Lessons 9-10
- `Weeks 11-16`: Capstone planning, implementation, polish, and reflection

Move slower if you need to. The goal is durable understanding, not speed-running syntax.

## How To Use This Course

1. Read the lesson goals first.
2. Type out the code examples yourself instead of only reading them.
3. Pause after each section and predict what the code will do.
4. Complete the embedded labs before reading the solution guide.
5. Keep a notebook of patterns that surprise you.
6. Build the capstone gradually rather than waiting until you "feel ready".

## Study Rules That Matter

- Do not memorize blindly; build mental models.
- When confused, reduce the code to a smaller example.
- When a bug appears, inspect inputs, outputs, and assumptions in that order.
- Prefer finishing small exercises consistently over waiting for long perfect study sessions.

## Recommended Setup

- Node.js LTS installed

- A modern browser with developer tools

## Outcome

If you complete the lessons, labs, and capstone honestly, you should have:

- stronger JavaScript fundamentals
- a clearer full-stack mental model
- better debugging habits
- a project you can discuss in an interview
- a realistic view of what junior engineers are expected to do

If you continue into the advanced track, you should also start building:

- system design vocabulary
- architectural tradeoff thinking
- stronger instincts around scalability, reliability, and boundaries
- better interview readiness for mid-level and senior conversations

If you work through the supplemental practice track, you should also build:

- stronger pattern recognition in everyday JavaScript and React code
- better instincts for reading small snippets quickly
- more confidence tracing state, rendering, events, and async flow

If you work through the interview review track, you should also build:

- faster recall for common JavaScript and React interview questions
- cleaner short-form explanations
- better confidence with feature and terminology questions
